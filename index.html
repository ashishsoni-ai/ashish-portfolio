01 — Evaluation · Razorpay Open Track

ClauseGuard — a test suite for agents that can promise money

A policy-conformance harness and deploy gate for customer-support agents. Thirty hand-written probes run against frozen agents. Every failing row carries the policy clause and the sentence that contradicts it, and both are checked as literal substrings, not paraphrased by a model.

  • Python
  • LLM-as-judge
  • RAG
  • Structured retrieval

02 — Adversarial ML · Fraud detection

HYDRA — an adaptive adversarial fraud lab

Breeds a diverse population of synthetic payment-fraud behaviours that target what a detector cannot see. It maps the blind spots as a 120-cell atlas, hardens the detector against them, then tests whether the hardening transfers to an attack family it has never seen, all at a constant false-positive budget.

  • Python
  • Quality-diversity search
  • Anomaly detection
  • pytest
Live demo ↗ Repository ↗

Runs entirely in a simulator over synthetic data. Fidelity scores are calibrated to the simulator, not to real card traffic.
